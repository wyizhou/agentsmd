# 我的 AGENTS.MD

这个仓库用来维护我自己的 AI 助手使用约定，把回答方式和协作习惯写下来，方便持续调整和复用。

思路很简单：先记录已经明确的偏好，在实际使用中逐步补充。不确定的内容暂时不写，尽量让每条约定简短、具体、容易执行。

仓库只保留两个文件：

- [AGENTS.MD](./AGENTS.MD)：具体的使用约定。
- [README.md](./README.md)：仓库说明和 MIT 授权。
